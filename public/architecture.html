OpenAPI 3.0 Tool Integration

Every feature—from proposal generation to red team analysis—is exposed as a strictly validated OpenAPI 3.0 REST endpoint. IBM watsonx Orchestrate discovers and executes these actions autonomously.

POST /generate-full-opportunity-package POST /api/deal-coach POST /api/red-team

RS256 JWT & API Key Security Layer

Embedded web chat uses RS256 signed JSON Web Tokens for authentication. Microservices enforce API key validation, rate limiting, and input sanitization to ensure zero prompt injection risks.

RS256 Keypair x-api-key Middleware express-rate-limit

IBM watsonx.ai Service Integration

Connects directly to regional watsonx.ai endpoints using official IAM SDK authenticators. System prompts enforce strict JSON output schemas, fallbacks, and deterministic response structure.

@ibm-cloud/watsonx-ai IAM Authenticator ca-tor Regional Cloud

Enterprise PDF & Document Generation

Server-side vector PDF generation engine built with PDFKit. Produces styled executive deal packages with metadata, multi-column tables, risk matrix, and brand styling.

PDFKit Engine Binary Buffer Streaming A4 Printable Format
