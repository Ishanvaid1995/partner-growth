OpenAPI 3.0 Tool Contracts
Every pre-sales feature—proposal blueprints, executive emails, technical handoffs, and deal coaching—is exposed via strictly typed OpenAPI 3.0 REST schemas for seamless watsonx Orchestrate discovery.
openapi.yaml Strict Schemas
RS256 Security & Data Isolation
Uses RSA 2048-bit private key signing for watsonx Assistant JWT token minting. Microservices enforce `x-api-key` header verification, rate limiting, and user profile data isolation.
RS256 JWT x-api-key Auth
watsonx.ai Model Integration
Connects to IBM Cloud regional endpoints (`ca-tor`) using official IAM authenticators. Employs `meta-llama/llama-3-3-70b-instruct` with strict system prompt formatting and JSON fallbacks.
Llama-3-70B IAM Authenticator
Executive Document Generation
Server-side vector rendering engine for high-resolution PDF exports (`PDFKit`) and native Word (`.docx`) package downloads with styled tables and executive metadata.
PDFKit Word (.docx) Engine
